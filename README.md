# ParentCare

ParentCare is a healthcare coordination app for families caring for older adults. The application lives in [`parentcare/`](./parentcare/); see its [README](./parentcare/README.md) for setup, security notes, and deployment instructions.

## Local development

On Windows, run `run_backend.bat` and `run_frontend.bat` in separate terminals, then open <http://127.0.0.1:5173/>.

The backend API documentation is at <http://127.0.0.1:8000/api/docs>.
